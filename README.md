# Система управления банковскими картами
## Функционал
### Пользователь:
- Просматривает свои карты
- Запрашивает блокировку карты
- Делает переводы между своими картами
- Смотрит баланс
### Администратор:
- Создает, блокирует, активирует, удаляет карты
- Управляет пользователями
- Видит все карты
## Стэк
- Java 21
- Spring Boot
- Spring Security + JWT
- Spring Data JPA
- PostgreSQL
- Liquibase
- Junit5
- Swagger/OpenAPI
- Docker
- Docker compose
## Инструкция запуска
1. Клонируйте репозиторий

```shell
git clone https://github.com/v7nny/bank-card.git
```

2. Перейдите в корневую папку проекта
3. Задайте значения переменным окружения в `.env` файле  
3.1 Для переменных `JWT_SECRET` и `ENCRYPTION_KEY` нужно задать значения длинной не менее 44 символов  
3.2 Значение для `JWT_LIFETIME` указывается в формате: `1s`/`1m`/`1h` или `PT1S`/`PT1M`/`PT1H`
4. Запустите приложение командой:

```shell
docker compose up
```
5. Приложение будет доступно по адресу: `http://localhost:8080`
6. Swagger документация: `http://localhost:8080/swagger-ui/index.html`
